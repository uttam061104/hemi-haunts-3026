# Hemi Town Haunt

Build a 3D horror game 'Hemi Town 3026' for Hemi Arcade 2 contest with FPP/TPP switch, custom player model using attachment 1, zombie ghosts using attachment 2, cracked dark Hemi town entity symbol using attachment 3, haunted graves for Jeremy, Joshua, JCV, Pranjal, and Akash, night horror atmosphere with jumpscares and audio, weapon progression starting with Stick Sword up to guns/swords, lobby with customizable player name, and Hemi testnet/onchain score recording.

This project was built with [Lovable](https://lovable.dev).
